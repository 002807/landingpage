# salon-success.at Landingpage

Entwurf "Moodboard mit Motion" für die Salon Success Academy by Elisabeth Prutti.

Vite, React und TypeScript. Keine weiteren Abhängigkeiten.

```
npm install
npm run dev
```

Bilder liegen in `public/images` und stammen aus Elisabeths Moodboard.

Offen mit Elisabeth: welche der 8 Workbooks es gibt, Gründungsjahr, Zahl der begleiteten Salons, Zustimmung der Stimmen (Selma, Gudrun), Impressum und Datenschutz.
